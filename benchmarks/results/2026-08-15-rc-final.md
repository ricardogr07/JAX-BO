# JAX-BO 0.2.2 benchmark evidence

Recorded from commit `04bfac3` on Windows CPU with Python 3.11.14, jax/jaxlib 0.10.2, numpy 2.4.6, scipy 1.17.1, pytest 9.1.1, and pytest-benchmark 5.2.3.

Command:

```text
.venv\Scripts\python.exe -m pytest benchmarks -q
```

The reported median is the median of four clean run medians. IQR values and
cross-session noise bands were retained during review but raw run files are
not part of the public source tree. Ratios below 1.00 are faster. Values inside
the noise band are not treated as meaningful regressions.
